# NCrystal plugin CrysExtn

This plugin is dedicated to study the extinction effects observed in polycrystalline matherials. Both Sabine's and Becker and Coppens' (BC) extinction models are implemented.

## Installation

Simply install NCrystal and then `pip install "git+https://github.com/XuShuqi7/ncplugin-CrysExtn"`

## Note

A jupyter notebook is attached in the folder "verification" for testing the implementation.
